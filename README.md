# AFPK 영플래너 재무설계 프로세스 데모 V0.2

2026-09-27 업데이트: 대안의 최종 값 직접 입력, 결과 카드, HTML 리포트 다운로드를 추가했습니다. `report.py`도 앱 파일들과 함께 배포해야 합니다.

### 대안 수정과 리포트 다운로드

- **05 대안 비교 → 최종 값 직접 입력:** 대안 월 저축액·기간·목표금액·연수익률을 직접 입력합니다. Enter 또는 다른 칸 클릭으로 확정하면 결과가 재계산됩니다. ‘대안 다시 계산’ 버튼도 사용할 수 있습니다. 결과 표는 읽기 전용입니다.
- 종전 증감폭 방식은 ‘증감으로 조정’에서 사용할 수 있습니다. 목표나 기준안 조건을 변경하면 직접 입력 대안은 새 기준으로 초기화됩니다.
- **06 인간 검토 → 재무설계 리포트 다운로드:** 현재 프로필·자산·현금흐름·비율·선택 목표·기준안과 대안·검토 메모를 HTML 문서로 받습니다. 입력과 메모를 먼저 확정한 뒤 다운로드하세요.
- HTML은 인터넷 없이 브라우저에서 열립니다. 문서의 ‘인쇄 / PDF로 저장’ 버튼으로 PDF 저장도 가능합니다. 직접 PDF 다운로드가 아닌 브라우저 인쇄 기능을 이용합니다.
- 데이터는 Streamlit 서버의 현재 세션 메모리에서 처리하지만 앱이 DB나 서버 파일로 영구 저장하지 않습니다. 다운로드한 파일은 사용자 기기에 남습니다. 기존 다운로드 문서는 변경되지 않으므로 입력 변경 후 다시 다운로드하세요.
- 리포트의 타임라인은 사례 템플릿, 선택 목표 분석은 현재 수정값입니다. 별도 V0.1 주택 상세 계산기 결과는 리포트에 포함하지 않습니다.

화면은 밝은 금융 앱 스타일이며 상단 요약 카드와 6단계 탭으로 구성합니다. 탭을 이동해도 입력과 계산은 유지됩니다. `design.py`와 `.streamlit/config.toml`을 함께 배포하세요. 로컬에서는 이 문서가 있는 폴더에서 실행해야 테마 설정이 적용됩니다.

가상의 고객 금융자산과 월 저축액으로 목표시점 예상 금융자산을 계산하는 한국어 Streamlit 앱입니다. 생성형 AI나 API 키를 사용하지 않습니다. 직접 지정하는 외부 패키지는 Streamlit 하나이며, 설치 시 Streamlit의 필수 의존 패키지는 함께 설치됩니다.

## 1. 설치 방법

1. [Python 공식 사이트](https://www.python.org/downloads/)에서 Python 3.12 또는 3.13을 설치합니다. Windows 설치 화면에서는 **Add python.exe to PATH**를 선택하세요.
2. `app.py`, `planning.py`, `design.py`, `requirements.txt`, `README.md`와 `.streamlit` 폴더를 함께 놓습니다. 이 문서가 있는 `outputs` 폴더를 그대로 사용해도 됩니다.
3. 해당 폴더를 탐색기로 열고 주소창에 `powershell`을 입력한 뒤 Enter를 눌러 터미널을 엽니다.
4. 아래 명령을 한 줄씩 실행합니다. 패키지 설치에는 인터넷 연결이 필요합니다.

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`python` 명령을 찾을 수 없다면 Python 설치 후 터미널을 다시 열어보세요. `py --version`이 동작하는 환경에서는 처음 두 명령의 `python`을 `py`로 바꿀 수 있습니다. 가상환경을 따로 활성화하지 않으므로 PowerShell 실행 정책을 변경할 필요가 없습니다.

macOS/Linux에서는 다음 명령을 사용합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## 2. 실행 방법

Windows에서 위 파일들이 있는 폴더의 터미널에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

macOS/Linux:

```bash
.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

브라우저가 자동으로 열리지 않으면 [로컬 앱](http://localhost:8501)을 여세요. 실행 중에는 터미널을 열어두고, 종료할 때는 `Ctrl+C`를 누릅니다. 포트 사용 중 오류가 나면 실행 명령 끝에 `--server.port 8502`를 붙이고 `http://localhost:8502`로 접속하세요.

고객 정보와 목표를 입력하면 결과가 자동 갱신됩니다. 금액은 **원**, 수익률은 **%** 단위입니다. 첫 화면에서 김참직 사례 또는 직접 입력을 선택합니다. 인간 검토 메모에 모델의 한계와 최종 판단을 기록하세요. 메모는 접속 세션에서만 유지되고 영구 저장되지 않으며, 새로고침이나 연결 종료 시 사라질 수 있습니다. 입력값을 바꿔도 메모 내용은 자동 갱신되지 않으므로 다시 검토해야 합니다.

### 6단계 화면 사용법

1. **고객 프로필:** 김참직 사례의 기본정보를 불러오거나 직접 입력합니다. 모드를 바꾸면 프로필·재무정보·목표 배분 설정이 초기화됩니다. 메모는 유지됩니다.
2. **현재 재무상태:** 여섯 자산, 자동차 할부, 월 소득·지출·저축을 수정합니다. 합계·비율·잉여금이 즉시 바뀝니다.
3. **재무목표:** 상시·단기·중기·장기 타임라인에서 목표를 확인하고 분석할 목표를 선택합니다. 기준연도 기본값은 사례의 2026년입니다. 날짜 범위 목표는 마지막 연도를 기본 분석시점으로 사용합니다.
4. **목표 달성 가능성 분석:** 사용할 금융자산과 배분율, 저축 배분율, 기간, 수익률을 입력합니다. 기존 미래가치 함수로 계산합니다. ‘주택목표 상세분석’ 펼침 영역은 V0.1의 입력·결과 화면을 보존한 독립 시나리오입니다.
5. **대안 비교:** 저축 증액, 기간 연장, 목표 조정, 수익률 변경을 각각 적용한 결과와 네 조건을 조합한 결과를 비교합니다. 추가 저축이 월 잉여금을 넘으면 경고합니다.
6. **인간 검토:** 계산 가정, 실행 가능성, 위험, 자금 중복배분과 최종 판단을 기록합니다.

## 4. 계산 방식

변수: 현재 금융자산 `A`, 매월 말 저축액 `P`, 목표기간(년) `Y`, 입력 연수익률(%) `R`, 목표금액 `T`.

```text
n = Y × 12
r = R / 100
i = (1 + r)^(1/12) − 1

현재 금융자산 미래가치 = A × (1 + i)^n
월 저축액 미래가치 = P × ((1 + i)^n − 1) / i
  단, R = 0이면 P × n
예상 금융자산 = 현재 금융자산 미래가치 + 월 저축액 미래가치
차액 = 예상 금융자산 − T
```

연수익률은 **연 실효수익률**로 해석합니다. 현재 자산은 기간 전체에 걸쳐 운용하고, 저축은 매월 말 납입합니다. 마지막 달 저축에는 수익이 붙지 않습니다. Python 표준 라이브러리 `math.log1p`와 `math.expm1`으로 위 수식을 구현하여 작은 수익률에서의 오차를 줄였습니다.

차액이 0 이상이면 단순 계산상 달성 가능, 음수이면 달성 어려움으로 표시합니다. 판정은 원 단위 표시 반올림 이전의 값으로 하되 부동소수점의 극미한 오차만 보정합니다. 달성 비율은 예상 금융자산/목표금액이며 확률이 아닙니다.

검산 예: 현재 자산 2,000만 원, 월 저축 100만 원, 5년, 수익률 0%이면 자산 미래가치 2,000만 원 + 저축 미래가치 6,000만 원 = 8,000만 원입니다. 목표가 1억 원이면 2,000만 원 부족입니다.

기존 계산기의 입력 범위: 나이 0~120세, 기간 1~50년, 수익률 -99~100%, 월 소득·저축 0~100억 원, 현재 자산·부채 0~1조 원, 목표 1원~1조 원. 이 범위는 테스트 입력 제한이며 수익률의 현실성을 의미하지 않습니다. 월 저축액이 월 소득보다 크면 검토 경고를 표시합니다.

### V0.2 재무상태와 비율

```text
총자산 = 여섯 자산 항목 합계
총부채 = 자동차 할부잔액
순자산 = 총자산 − 총부채
부채비율 = 총부채 / 총자산 × 100
순자산비율 = 순자산 / 총자산 × 100
월 소비지출 = 고정지출 + 변동지출
월 잉여현금흐름 = 가처분소득 − 고정지출 − 변동지출 − 저축·투자
지출·저축·잉여 비율 = 해당 금액 / 가처분소득 × 100
비상예비자금 개월 수 = 비상예비자금 / 월 소비지출
```

분모가 0인 비율은 ‘계산 불가’로 표시합니다. 음수 순자산과 적자 현금흐름은 그대로 표시합니다. 비율에 대한 적정성 기준을 자동 판정하지 않습니다.

김참직 기본값 검산: **총자산 63,600,000원 · 총부채 3,600,000원 · 순자산 60,000,000원 · 월 잉여 131,000원**. 월 소비지출 2,263,000원, 비상자금 약 4.42개월입니다.

### 목표별 해석과 한계

- 분석 자산은 선택한 예·적금/비상자금/ETF/주택청약 합계 × 배분율입니다. 보증금·차량은 제외하고, 비상자금은 유지 목표 이외에서 기본 제외합니다. 저축액은 STEP 2의 저축·투자 × 목표 배분율입니다.
- 여러 목표는 **독립 시뮬레이션**입니다. 한 목표에 쓴 돈을 차감해 다음 목표를 계산하는 통합 자금계획은 아닙니다. 각 결과를 합산하지 마세요.
- 전세 목표는 본인 준비금을 분석합니다. 배우자 자금과 대출은 자산에 더하지 않으며 조달계획의 합계만 점검합니다.
- 자가 목표는 현재가치 매입가격과 부대비용을 합칩니다. 미래 물가·주택가격 상승은 반영하지 않으므로 명목 미래자산과 현재가치 목표 간 비교에 한계가 있습니다.
- 은퇴 월 생활비는 `월 생활비 × 12 × 준비기간`으로 일시금 목표에 환산합니다. 기본 준비기간 25년, 기본 은퇴시점 60세는 사례 사실이 아닌 수정 가능한 가정입니다. 연금, 물가, 은퇴 후 수익·인출 위험은 미반영입니다.
- 비상자금 유지 목표는 현재 잔액과 먼저 비교합니다. 미래가치는 추가 적립 분석이며 인출·지출에 따른 지속 유지 여부를 판단하지 않습니다.
- 자동차 할부 목표는 현재 잔액에 연동됩니다. 잔액이 0이면 완료로 표시하며, 할부 상환 스케줄과 이자는 계산하지 않습니다.
- 대안 비교는 기간 최대 50년, 변경 후 연수익률 -99~100%로 제한하고 실제 적용값을 표에 표시합니다. 높은 수익률은 위험 증가를 동반하며 추천을 의미하지 않습니다.

## 모델의 한계와 인간 검토

- 세금, 물가, 수수료, 소득변화, 수익률 변동을 반영하지 않습니다.
- 현재 부채는 재무상태표와 상환 준비금 목표에 반영합니다. **미래 금융자산과 목표달성 판정에서 부채를 자동 차감하지 않으며**, 부채 이자·상환 스케줄도 계산하지 않습니다.
- 나이는 목표시점 나이 표시용, 월 소득은 저축액 점검용입니다. 소득을 자산에 추가하지 않습니다.
- 모든 금융자산을 동일 수익률로 운용하고 같은 금액을 계속 저축한다고 가정합니다. 생활비·비상자금·투자위험을 반영하지 않습니다.
- 실제 개인정보를 입력하지 마세요. 테스트 결과는 수익이나 실제 목표달성을 보장하지 않습니다. 사람이 가정과 부채 부담 등을 검토하고 최종 판단을 작성해야 합니다.

UI 구성과 실행 방식 참고: [Streamlit 공식 문서](https://docs.streamlit.io/develop/quick-reference/cheat-sheet).

1. GitHub의 앱 전용 저장소에 `app.py`, `planning.py`, `design.py`, `requirements.txt`, `README.md` 및 `.streamlit/config.toml`을 올립니다. 기존 저장소는 그대로 재사용합니다. `.venv`, `work`, 실제 고객 정보는 올리지 않습니다.
2. Streamlit Community Cloud에 로그인하고 GitHub 계정을 연결합니다.
3. 앱 생성 메뉴에서 해당 저장소와 파일이 있는 브랜치를 선택합니다. 메인 파일 경로는 `app.py`로 지정합니다.
4. 고급 설정에서 Python 3.12를 선택하고 배포합니다.
5. 실행 완료 후 앱 공유 설정을 확인하여 링크를 받은 사람이 볼 수 있게 설정합니다. 발급된 `https://….streamlit.app` 주소를 공유합니다.

기존 폴더 구조 그대로 저장소에 올렸다면 메인 파일 경로는 `outputs/app.py`입니다. `requirements.txt`는 `app.py`와 같은 폴더에 두세요. 배포 후에도 메모는 영구 저장되지 않습니다.

배포 확인: 로그인하지 않은 브라우저에서 공유 주소를 열어 입력·결과·메모 동작을 확인하세요. 기본 예제에서 연수익률을 0%로 바꾸면 예상 금융자산은 8,000만 원입니다.

공식 안내: [앱 배포](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy), [앱 공유](https://docs.streamlit.io/deploy/streamlit-community-cloud/share-your-app).
